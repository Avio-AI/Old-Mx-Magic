# Old Mx Magic (retired 3 NOV 2026)

This was the Mx Magic fleet app (G600 app in `g600.html`, G550 app in Avio-AI/G550-troubleshooter).
It is retired: every page now forwards to **Avio.AI**, https://avio-ai.github.io/avio-app/, which replaced it.
Settings and cases on a device carry over (same site), and cases stay in the shared cases repo.

The last working version of the app is kept in this repo's history on the branch `last-working-app`.
